# Bitget submission checklist

- [ ] Register with Bitget and record the matching UID.
- [ ] Select AI Trading Desk → Information insights and signal generation.
- [ ] Publish a public GitHub repository with setup and usage instructions.
- [ ] Provide a public demo URL or reproducible local-run instructions.
- [ ] Show one complete research task from question to evidence to decision.
- [ ] Include desktop and mobile screenshots.
- [ ] Record a demo video under three minutes if the demo requires login.
- [ ] Publish a qualifying X post tagging `@Bitget_AI` and `#BitgetHackathon`.
- [ ] Exclude `data/`, `.env`, API keys, and personal runtime state.
- [ ] Submit through the official Bitget form before September 21, 2026 (UTC+8).
